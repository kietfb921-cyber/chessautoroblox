# chessautoroblox

Roblox chess auto-play script (source, không obfuscate).

## Dùng

1. Mở game cờ trên Roblox, vào bàn đấu.
2. Chạy `chess.lua` bằng executor.
3. Menu hiện góc phải trên, kéo được. Bật **Auto Play Chess**.

## Trạng thái script

Script kiểm tra trạng thái khi khởi động tại:

```
https://anotepad.com/notes/f9f3kywg
```

- Nội dung ghi `online` → script chạy bình thường.
- Nội dung khác → hiện thông báo **Script đã ngưng hoạt động** và dừng.
